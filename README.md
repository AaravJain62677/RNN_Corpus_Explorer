# RNN Corpus Explorer

## Overview

A modular framework for experimenting with:

- RNNs
- LSTMs
- GRUs

for character-level neural language modeling.

---

## Features

- Dataset agnostic
- Character-level modeling
- Text generation
- Training visualization
- Streamlit demo
- RNN/LSTM/GRU comparison
